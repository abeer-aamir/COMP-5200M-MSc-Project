A small stateful registry needs stable per-replica storage and predictable recovery without exposing the service to unrelated workloads.

- Create a Namespace named `medium-stateful-ns`.
- In namespace `medium-stateful-ns`, create a ConfigMap named `registry-prefix` containing exactly one key, `PREFIX`, with value `registry`.
- In namespace `medium-stateful-ns`, create an Opaque Secret named `registry-suffix` containing exactly one key, `SUFFIX`, with value `stable`.
- In namespace `medium-stateful-ns`, create a headless Service named `registry-headless` with `clusterIP: None`, `publishNotReadyAddresses: false`, selector `app=registry`, and TCP port 8080 targeting named port `http`.
- In namespace `medium-stateful-ns`, create a StatefulSet named `registry` with `serviceName: registry-headless`, exactly two replicas, and pod label `app=registry`. Its single container must be named `registry`, use `busybox:1.36.1`, set `PREFIX` from `registry-prefix/PREFIX`, set `SUFFIX` from `registry-suffix/SUFFIX` using `secretKeyRef`, expose named TCP port `http` on 8080, mount a per-pod claim named `data` at `/data`, and run `sh -c "if [ ! -f /data/index.html ]; then printf \"%s-%s-%s\\n\" \"$PREFIX\" \"$HOSTNAME\" \"$SUFFIX\" > /data/index.html; fi; httpd -f -p 8080 -h /data"`. Use an HTTP readiness probe on path `/` and named port `http` with `periodSeconds: 5`. Its `volumeClaimTemplates` entry named `data` must request exactly `64Mi` with `accessModes: ["ReadWriteOnce"]`. Both pods must become Ready within 90 seconds. After an evaluator writes `oracle-marker` to `/data/oracle-marker` in pod `registry-0` and deletes that pod, `registry-0` with a different UID must become Ready within 90 seconds and still contain the exact marker. During the same recovery, `registry-headless` must return to exactly two Ready endpoint addresses within 90 seconds.
- Harden every `registry` pod with pod-level `runAsNonRoot: true`, `runAsUser: 1000`, `runAsGroup: 1000`, and `fsGroup: 1000`, and container-level `allowPrivilegeEscalation: false`, `readOnlyRootFilesystem: true`, and `capabilities.drop: ["ALL"]`.
- In namespace `medium-stateful-ns`, create a NetworkPolicy named `registry-ingress` selecting `app=registry`. It must allow ingress on TCP 8080 only from pods in the same namespace labelled `access=registry`, with all other ingress to the selected pods denied.
- In namespace `medium-stateful-ns`, create a PodDisruptionBudget named `registry-pdb` selecting `app=registry` with `minAvailable: 1`.
- Configure StatefulSet `registry` with `persistentVolumeClaimRetentionPolicy.whenDeleted: Retain` and `persistentVolumeClaimRetentionPolicy.whenScaled: Retain`.
- Configure StatefulSet `registry` with `podManagementPolicy: OrderedReady` and `RollingUpdate` update strategy with `partition: 0`.

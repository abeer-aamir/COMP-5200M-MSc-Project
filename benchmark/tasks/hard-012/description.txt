Create a three-member retained journal in `hard-journal-ns`. We need stable ordinal responses, a partitioned update policy and a bounded check of every member.

Use immutable ConfigMap `journal-prefix` with only `PREFIX=journal`, immutable Opaque Secret `journal-key` with only `KEY=k1`, and headless Service `journal-headless` with `clusterIP: None`, `publishNotReadyAddresses: false`, selector `app=journal`, and TCP 8080 to named `journal-http`.

StatefulSet `journal` has three replicas, `serviceName: journal-headless`, Parallel pod management, RollingUpdate partition two, pod label `app=journal`, and Retain claim policies for scale and deletion. Its init container writes `seed\n` to `/data/seed` only if absent. Probe `/` every five seconds, disable API-token mounting, and make all three replicas Ready within 180 seconds.

ClusterIP Service `journal-svc` selects the members and exposes port 80 to the named target. It should have exactly three Ready addresses, and the stable names must return `journal-journal-0-k1-seed\n`, `journal-journal-1-k1-seed\n`, and `journal-journal-2-k1-seed\n` within 180 seconds.

Job `journal-smoke` carries label `access=journal`. Its one `busybox:1.36.1` container gives each stable name at most 60 attempts, two seconds apart, to return its exact ordinal body, then prints `journal-smoke-ok`. Use `restartPolicy: Never`, no backoff and a 180-second deadline. It must Complete in 180 seconds and log exactly `journal-smoke-ok\n`.

Run init, journal and smoke containers as non-root UID/GID 1000 with `fsGroup: 1000`, no privilege escalation, read-only root filesystems and all capabilities dropped. Only member claims are writable. Deny journal and smoke ingress, allow journal TCP 8080 only from `access=journal`, and permit smoke egress only to journal pods on 8080 plus DNS UDP/TCP 53.

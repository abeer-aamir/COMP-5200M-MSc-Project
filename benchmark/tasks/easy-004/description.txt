A small internal banner service needs one protected configuration value and should recover automatically if its pod is deleted. Keep it in a namespace named `easy-restart-ns`.

Store `BANNER=hello-restart` as the only entry in an immutable Opaque Secret called `banner-secret`. Run the service as a one-replica Deployment named `restart-web`, using pod label `app=restart-web`. Its only container is named `web`, uses `busybox:1.36.1`, and receives `BANNER` from `banner-secret/BANNER` through a `secretKeyRef`. Start it with `sh -c "mkdir -p /work && printf 'ready\n' > /work/index.html && httpd -f -p 8080 -h /work"`, expose TCP container port 8080, and check readiness over TCP on that port every five seconds.

Create a ClusterIP Service named `restart-svc` selecting `app=restart-web`, with TCP port 8080 targeting container port 8080. After the first pod is Ready, an evaluator may delete it. A replacement with a different UID must become Ready within 60 seconds, after which `restart-svc:8080` must return exactly `ready` followed by a newline.

Add a ResourceQuota called `restart-quota`. Its complete hard-limit set should be exactly five pods, two Services, and three Secrets.

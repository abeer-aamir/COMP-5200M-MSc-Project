A platform team needs a small hardened health endpoint and a paused scheduled checker that can be exercised before anyone enables its schedule. Put the setup in `medium-check-ns`.

Create ConfigMap `check-content` with only `index.html=check-ready\n`. Run Deployment `check-web` with two replicas and pod label `app=check-web`. Each pod has one container named `web`, using `busybox:1.36.1`; mount the complete ConfigMap read-only at `/www`, run `httpd -f -p 8080 -h /www`, and expose TCP 8080 as named port `http`. The HTTP readiness probe should check `/` on that named port, with a two-second initial delay, five-second period, and failure threshold of three. Both replicas need to be Ready within 60 seconds. Use pod-level non-root UID and GID 1000 with `fsGroup: 1000`, plus container-level no privilege escalation, a read-only root filesystem, and all capabilities dropped.

Configure the Deployment for RollingUpdate with `maxUnavailable: 0`, `maxSurge: 1`, `minReadySeconds: 5`, `progressDeadlineSeconds: 90`, and `revisionHistoryLimit: 2`. Add `check-pdb` selecting the web pods with `minAvailable: 1`.

Expose the endpoint through ClusterIP Service `check-svc`, selecting `app=check-web`, with TCP port 80 targeting named port `http`. A permitted client in the namespace should receive exactly `check-ready` followed by a newline from `http://check-svc`. NetworkPolicy `check-ingress` should select the web pods and allow TCP 8080 only from same-namespace pods labelled `access=checker`, denying all other ingress to them.

Create a suspended CronJob called `scheduled-check`, scheduled for `*/5 * * * *`, using `Forbid` concurrency and retaining one successful and one failed Job. Label its pod `access=checker`; use one container named `checker` with `busybox:1.36.1`, and run `sh -c "i=0; until body=$(wget -qO- http://check-svc); do i=$((i + 1)); [ \"$i\" -ge 10 ] && exit 1; sleep 2; done; test \"$body\" = check-ready && echo check-ok"` with `restartPolicy: Never`. When an evaluator creates one Job from the suspended CronJob, it must Complete within 60 seconds and its only pod must log exactly `check-ok` followed by a newline.
